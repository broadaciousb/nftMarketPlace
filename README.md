# Ultraverse

A full-stack ecommerce nft store where users can browse different nfts to purchase.

## Technologies
- React
- JavaScript
- CSS
- FontAwesome

## Features
- Responsive design
- Dynamic Data Representation

## Future Improvements
- Connect Stripe for payment processing.
- Implement user access to nft after purchasing

## Author
Developed by Broady Butler

## Getting Started

This project was bootstrapped with [Create React App](https://github.com/facebook/create-react-app).

1. Clone Repository

```bash
git clone https://github.com/broadaciousb/nftMarketPlace
```

2. Install Dependencies

```bash
npm install
```

3. Run Development Server

```bash
- npm start
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
